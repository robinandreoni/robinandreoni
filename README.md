### 👨‍💻 Chi Sono

Sviluppatore software e ideatore dell'ecosistema **Tortuga Italia**. Mi dedico alla progettazione e realizzazione di applicazioni desktop stand-alone, software mobile Android, piattaforme multimediali/streaming e integrazioni con intelligenza artificiale per l'elaborazione vocale e l'automazione.

- 🌐 **Sito Ufficiale:** [www.tortugaitalia.com](https://www.tortugaitalia.com)
- 📍 **Focus Attuale:** Architetture multimediali, applicazioni stand-alone in Python, player nativi e trascrizione vocale AI locale.
- 💡 **Filosofia di sviluppo:** Performance, indipendenza, interfacce intuitive e codice pulito.
